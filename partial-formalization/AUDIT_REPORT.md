## 原文与定义核对

核对来源：[Zudilin, arXiv:1504.07696v2，第 4 节](https://arxiv.org/html/1504.07696v2#S4)，检索日期 2026-10-22。式 (8) 的第一种有限和、Lemma 3 的递推及初值与源码逐项比较。原文末段是关于变量 x=t³ 的非正实半轴零点观察，包含 0；本目录并未证明该一般结论。

`OriginalSum.poch` 是长度 n 的升阶乘乘积；`term` 包含四个升阶乘及 k!、(n-k)! 分母；`B` 再乘 1/n!，范围为 k=0,…,n。它精确实现式 (8) 第一行，非代理定义。自然数截断减法只在上述合法范围内用于求和，不改变有限和。第二种有限和形式没有在本目录连接或证明。

`C` 是实际递归定义的实系数多项式，`P=C/(n!)²`。归一化后已证明

```text
P[n+2] = N(a,n)/(n+2)² · P[n+1]
         + (x-(n+a)³)/((n+2)²(n+1)) · P[n],
N(a,n)=2n²+3n(a+1)+a²+3a+1,
P[0]=1, P[1]=a².
```

乘回非零分母即为原文 Lemma 3 递推。`C_recurrence` 为定义展开的 `rfl`；有实质证明的是缩放后的 `P_recurrence` 和相关评估归纳。这里的“递推等价”仅指 **C 与 P 的归一化递推等价**，不包含有限和 B 与递推族 P 等价。

## 已编译层的精确范围

| 层 | 实际保证及条件 |
|---|---|
| 递推、初值、唯一性 | a 为任意实数，n 为任意自然数。`recurrence_unique` 要求输入族 F 满足初值和递推，未假定其根性质，也未证明 B 满足这些条件。 |
| 两个评估恒等式 | 对所有实 a 和自然数 n，P(a,n)(0)=(a)ₙ²/(n!)²；P(a,n)(−a³)=∏ₖ₌₀ⁿ⁻¹(k²+ka+a²)/(n!)²。证明为真正的二步归纳与代数恒等式。 |
| 正性和非零性 | 第二个评估值的严格正性及 P 非零要求 a≠0；第一个评估值严格正性使用 `Nonexceptional a := ∀ k:ℕ, a+k≠0`。后者排除所有非正整数，比固定 n 所需条件更强，但已明确写入假设。 |
| 符号反转 | q 为实数，要求 P[n+1](q)=0、q<(n+a)³，并给定 P[n](q) 的正或负号，才推出 P[n+2](q) 的反号。尚未证明这些条件对一般所有相邻根同时成立。 |
| 端点界 | endpoint(a,n)=min(0,(a+n−1)³)，证明其单调及下一端点≤(n+a)³；未把一般根定位到端点左侧。 |
| n=2 | P(a,2)(x)=(x+a²(a+1)²)/4。对任意实 a、任意复 z，根当且仅当 z=−a²(a+1)²；因而所有复根都是真实非正数。严格小于移动端点的结论带参数排除条件。这里 n=2 是序列下标，P(a,2) 在 x 中为一次多项式。 |
| 原始 B 的消项 | t=0、t=−a、t=a+n−1 的公式适用于任意复 w、a；不偷加根单位假设。 |
| 原始 B 的移动端点乘积 | `w²+w+1=0` 时得到 ∏(k²−ks+s²)/(n!)²，s=a+n−1；当 a 实、s≠0 时，B 的值等于某个严格正实数的复数嵌入。 |

`P_two_all_complex_roots` 的 z 量化域确为 ℂ，并非先假定 z 实。其假设只有“z 为根”，没有把“根为非正实数”预放入上下文。独立的 `ReviewChecks.lean` 又证明对每个 a，P(a,2) 非零且确有复根，排除空真疑虑；这两项并非原有 53 个定理的一部分。

## 尚未连接层与不能推出的结论

1. **原始和式 B→递推族 P 的全 n 连接缺失。** 应证明：对实 a、复 t、自然数 n、复 w，在 `w²+w+1=0` 下，`B w (a:ℂ) t n = (P a n).eval₂ Complex.ofRealHom (t³)`。初值、原始和式满足递推、t³ 多项式结构均需要相应正式证明。现有唯一性定理不能自动补齐这一点。
2. 因此 B 在 t=a+n−1 的正性尚不能转移给 P 在 x=(a+n−1)³ 的评估；更不能直接得到 min 端点的统一一般归纳。
3. 一般 n 的次数、首项系数、严格交错、根数耗尽、全体复根为非正实数仍未完成。
4. a=0 且 n≥2 的一般非零性与例外参数的系数极限闭包仍未完成；n=2 的完整结果不能替代这些一般步骤。
5. 没有形式化论文的 `exp(2πi/3)` 表达式及其代数条件；当前乘积定理是针对满足明确代数条件的任意 w 的条件定理。
